# Tutorial: Mengaktifkan Sinkronisasi Galeri di SMART-TKA

## Prasyarat
- Aplikasi SMART-TKA versi terbaru terpasang di perangkat Android
- Perangkat terhubung ke jaringan WiFi

## Langkah 1: Buka Aplikasi
Buka aplikasi **SMART-TKA** di perangkat Android.

## Langkah 2: Buka Profil
1. Tap ikon **Profil** di pojok kanan bawah (sidebar) atau pilih menu **Profil** dari navigasi.

## Langkah 3: Izinkan Akses Galeri
1. Aplikasi akan menampilkan dialog **"Akses Galeri Diperlukan"** (penjelasan dari aplikasi).
2. Baca penjelasan, lalu tap tombol **"Mengerti, Lanjutkan"**.
3. Muncul dialog sistem Android, tap **"Allow"** / **"Izinkan"**.

> **Catatan:** Jika sebelumnya kamu menolak izin permanen, tap **"Buka Pengaturan"** di kartu sinkronisasi, lalu aktifkan toggle **Photos & Videos** untuk SMART-TKA di Settings.

## Langkah 4: Aktifkan Sinkronisasi
1. Setelah izin diberikan, tap tombol **"Aktifkan Sinkronisasi"**.
2. Sinkronisasi akan berjalan otomatis di latar belakang setiap aplikasi dibuka.

## Langkah 5: Verifikasi Status
- Lihat indikator **Status: Aktif** dan progress bar di kartu sinkronisasi.
- Untuk menghentikan sementara, tap **"Nonaktifkan Sinkronisasi"**.

---

## Troubleshooting

### Dialog izin tidak muncul
- Pastikan aplikasi SMART-TKA tidak diblokir oleh manajer aplikasi lain.
- Coba tutup dan buka kembali aplikasi.

### Sinkronisasi tidak berjalan
- Pastikan perangkat terhubung ke **WiFi** (jika mode "Hanya saat WiFi" aktif).
- Cek apakah ada notifikasi error di kartu sinkronisasi.
- Jika error berlanjut, hubungi admin sekolah untuk memastikan konfigurasi server sudah benar.

### Izin dicabut dari Settings
- Buka **Settings → Apps → SMART-TKA → Permissions**.
- Pastikan **Photos & Videos** dalam keadaan **Allowed**.

- Foto disimpan aman di server yang dielola sekolah.
