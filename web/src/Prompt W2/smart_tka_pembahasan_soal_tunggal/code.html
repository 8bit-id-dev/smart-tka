Penalaran Umum - Kuantitatif

tag Bilangan Pecahan signal_cellular_alt_2_bar Mudah
Jika x = 1/3 dan y = 25%, maka manakah pernyataan di bawah ini yang benar?
A
x < y
B
x > y
check_circle
C
x = y
D
x dan y tidak dapat ditentukan
task_alt Jawaban Anda Benar!

lightbulb Pembahasan

Untuk membandingkan dua nilai tersebut, kita perlu menyamakannya ke dalam bentuk yang sama, misalnya bentuk pecahan desimal atau pecahan biasa.

x = 1/3 ≈ 0.333...

y = 25% = 25/100 = 1/4 = 0.25

Karena 0.333... > 0.25, maka jelas bahwa x > y.

Oleh karena itu, pernyataan yang benar adalah B.
